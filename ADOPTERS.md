## How to Add Your Organization

We'd love to hear about your Knetz deployment! To add your organization:

1. Fork this repository
2. Add your entry to the appropriate table above
3. Submit a pull request with the title: "Add [Your Org] to ADOPTERS.md"
4. Include a brief description of your use case (optional)

### Information to Include

**Required:**
* Organization name
* Use case (brief description)
* Environment (Production/Staging/Development/Testing)

**Optional:**
* Contact (GitHub handle or email)
* Date started using Knetz
* Link to case study or blog post
* Logo (add to `/docs/adopters/logos/`)

### Example Entry

```markdown
| Acme Corp | Cross-cluster dependency tracking for 50+ microservices | Production | @acme-sre | Jan 2026 |
```

## Deployment Patterns

Common deployment patterns from our adopters:

### Pattern 1: Multi-Cloud Management
* **Clusters**: AWS EKS, GCP GKE, Azure AKS
* **Services**: 100+ microservices
* **Use Case**: Unified version tracking across clouds

### Pattern 2: Dev/Staging/Prod Parity
* **Clusters**: 3 clusters (dev, staging, prod)
* **Services**: 20+ microservices
* **Use Case**: Version consistency across environments

### Pattern 3: Multi-Tenant SaaS
* **Clusters**: Tenant-specific clusters
* **Services**: Shared platform services
* **Use Case**: Tenant isolation with shared dependencies

> **Note**: These patterns will evolve as we gather more real-world deployments.
